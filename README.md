# Тестовое задание: поиск транзакций в Ethereum

## Описание
Приложение на **FastAPI**, которое позволяет регистрировать запросы на отслеживание входящей транзакции  
(по адресу получателя, адресу контракта и ожидаемой сумме). В фоновом режиме сервис мониторит блокчейн Ethereum  
и при нахождении подходящей транзакции логирует её в консоль и снимает запрос с отслеживания.

## Требования
- **Python 3.13**
- Установленные зависимости из `requirements.txt`

## Подготовка и запуск

### 1. Настройка конфигурации
1.1 Скопируйте файл `configs/config.yml.example` в `configs/config.yml`.

1.2 Заполните параметры внутри `configs/config.yml` (адреса RPC, WebSocket, порт для запуска, хост).

### 2. Установка зависимостей
`pip install -r requirements.txt`

### 3. Запуск приложения
3.1 Запуск напрямую (Python)

`python main.py -c configs/config.yml`

Параметр -c указывает путь к файлу конфигурации. Если его не указывать, используется значение по умолчанию `./configs/config.yml`

3.2 Запуск в Docker

Соберите Docker-образ:

`docker build -t eth-tx-tracker .`

Запустите контейнер:

`docker run -p 8000:8000 eth-tx-tracker`

Порт в yml конфигурации, Dockerfile и команде запуска должен совпадать.

### 4. Взаимодействие с API

После запуска приложение доступно по адресу:
http://127.0.0.1:8000

Документация (Swagger UI) доступна по адресу:
http://127.0.0.1:8000/docs

Как работать с отслеживанием
- Чтобы отслеживать только ETH-транзакции, оставьте поле contract_address равным None или пустым.
- Для ERC-20-токенов укажите адрес контракта.
- Укажите адрес отслеживания и сумму.
- Приложение может одновременно отслеживать несколько разных токенов (и несколько адресов).
найденные транзакции логируются (выводятся в консоль/логи сервиса) и перестают отслеживаться.
