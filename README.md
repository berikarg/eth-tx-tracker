# Тестовое задание: поиск транзакций в Ethereum

## Описание
Приложение на FastAPI, которое позволяет зарегистрировать запрос на отслеживание входящей транзакции
(по адресу получателя, адресу контракта и ожидаемой сумме), и в фоновом режиме ищет новую транзакцию
в блокчейне Ethereum, удовлетворяющую этим параметрам.
